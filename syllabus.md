# Ementa - Desenvolvimento Web Básico com Python

**Carga horária:** 30h (15 aulas × 2h)
**Público:** Iniciantes absolutos em desenvolvimento web
**Pré-requisitos:** Lógica de programação básica (variáveis, loops, funções)

---

## Módulo 1: Fundamentos de Frontend (Aulas 1-4)

| Aula | Tópico           | Conteúdo Principal                                               |
| ---- | ---------------- | ---------------------------------------------------------------- |
| 1    | HTML Básico      | Estrutura semântica, tags, atributos, anatomia do documento      |
| 2    | CSS Básico       | Box model, flexbox, variáveis, design responsivo                 |
| 3    | Formulários HTML | Tipos de input, labels, validação nativa, acessibilidade         |
| 4    | Assets Estáticos | Linkar CSS, organizar arquivos estáticos, dev tools do navegador |

## Módulo 2: Template Engine (Aulas 5-7)

| Aula | Tópico                | Conteúdo Principal                                  |
| ---- | --------------------- | --------------------------------------------------- |
| 5    | Jinja2 Básico         | Variáveis, condicionais, loops, sintaxe de template |
| 6    | Herança de Templates  | Layout base, blocks, extends, princípio DRY         |
| 7    | Partials de Templates | Includes, macros, componentes reutilizáveis         |

## Módulo 3: Backend com Flask (Aulas 8-11)

| Aula | Tópico                    | Conteúdo Principal                                   |
| ---- | ------------------------- | ---------------------------------------------------- |
| 8    | Flask Básico              | App factory, rotas, request/response, rodar servidor |
| 9    | Rotas e Métodos HTTP      | GET/POST, url_for, redirect, padrão PRG              |
| 10   | Tratamento de Formulários | request.form, validação server-side, flash messages  |
| 11   | Blueprints e Estrutura    | Rotas modulares, app factory, organização do projeto |

## Módulo 4: Banco de Dados e CRUD (Aulas 12-15)

| Aula | Tópico             | Conteúdo Principal                                                         |
| ---- | ------------------ | -------------------------------------------------------------------------- |
| 12   | SQLite e Models    | sqlite3, gerenciamento de conexão, funções CRUD                            |
| 13   | Listagem e Criação | Renderizar tabelas, fluxo de criação, validação, feedback                  |
| 14   | Edição e Exclusão  | Formulários pré-preenchidos, confirmação, segurança de métodos             |
| 15   | Polimento e Deploy | Páginas de erro, logging, gunicorn, variáveis de ambiente, próximos passos |

---

## Competências Finais

- [ ] Escrever HTML semântico e estilizar com CSS
- [ ] Usar templates Jinja2 com herança
- [ ] Construir aplicação Flask do zero
- [ ] Tratar formulários com validação server-side
- [ ] Persistir dados em SQLite com camada de models
- [ ] Implementar CRUD completo (Create, Read, Update, Delete)
- [ ] Organizar código com Blueprints
- [ ] Debugar erros comuns e fazer deploy local
