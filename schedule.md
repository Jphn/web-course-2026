# Cronograma - 15 aulas de 2h

Cada aula combina revisão, demonstração, prática guiada e um exercício curto.

| Aula | Tema | Entrega |
| --- | --- | --- |
| 1 | Como uma página web funciona e HTML | Página inicial |
| 2 | CSS e layout | Página estilizada |
| 3 | Formulários HTML | Formulário visual |
| 4 | Arquivos estáticos e revisão | Pequeno site estático |
| 5 | Jinja: variáveis e condicionais | Template dinâmico |
| 6 | Jinja: loops e herança | Layout com páginas |
| 7 | Includes e macros simples | Componentes reutilizáveis |
| 8 | Primeiro aplicativo Flask | Aplicação rodando |
| 9 | Rotas e links | Navegação Flask |
| 10 | GET, POST e redirect | Formulário funcionando |
| 11 | Validação e mensagens | Feedback para o usuário |
| 12 | SQLite e conexão | Tabela `items` |
| 13 | Criar e listar | Primeiro fluxo CRUD |
| 14 | Editar e excluir | CRUD completo |
| 15 | Revisão e apresentação | Projeto final explicado |

O professor pode mencionar testes, autenticação e deploy como próximos passos,
sem transformar esses tópicos em novas exigências durante o curso.
