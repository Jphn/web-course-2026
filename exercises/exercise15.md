# Exercício 15 - Revisar e explicar

## Objetivo

Revisar o projeto e preparar uma demonstração de cinco minutos.

## Roteiro

1. Inicie o projeto com `python run.py`.
2. Mostre a navegação e a lista de itens.
3. Crie um item válido.
4. Teste uma validação com dados inválidos.
5. Edite o item criado.
6. Exclua o item.
7. Explique o caminho de um item: formulário, rota, função do modelo, banco
   de dados e template.

## Critérios de sucesso

- o fluxo CRUD funciona do início ao fim;
- a demonstração identifica os arquivos principais;
- a pessoa estudante consegue explicar a função de `routes.py` e `models.py`;
- o projeto inicia sem erro em um ambiente limpo.
