# Exercício 1 - HTML Básico

## Objetivo

Criar `about.html` com estrutura semântica.

## Instruções

1. Copiar `index.html` para `about.html`
2. Mudar `<title>` para "Sobre"
3. Substituir conteúdo do main por:
    - `<h2>Sobre</h2>`
    - Parágrafo sobre você
4. Garantir que links da nav funcionem entre páginas

## Teste

Abrir ambos arquivos no browser, navegar via links.

## Critério de Sucesso

- HTML5 válido (validador W3C)
- Tags semânticas usadas
- Navegação funciona
