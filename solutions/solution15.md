# Solução 15 - Revisão

O projeto final reúne:

- templates HTML para exibir páginas e formulários;
- `routes.py` para receber requisições e redirecionar;
- validação e mensagens para orientar a pessoa usuária;
- `models.py` para executar consultas parametrizadas;
- SQLite para persistir os itens;
- operações de criar, listar, editar e excluir.

A demonstração deve mostrar o fluxo CRUD e explicar como os dados passam do
formulário, pela rota e pelo modelo, até o banco e a lista.
